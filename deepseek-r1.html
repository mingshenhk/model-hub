DeepSeek · 1.5B

DeepSeek R1 Distill Qwen 1.5B

DeepSeek R1 Distill Qwen 1.5B is a compact model trained to imitate some reasoning behaviour of DeepSeek R1.

View on Hugging Face

About this model

It uses a Qwen2 1.5B base and was fine-tuned with examples from DeepSeek R1. Its training gives extra attention to reasoning tasks such as maths and logic. It may show a longer reasoning-style response than a general chat model, but the explanation can still contain mistakes.

Main features

  • About 1.5B parameters, making it a small reasoning model.
  • Distillation transfers response patterns from a larger teacher model.
  • It is interesting to try on maths and logic questions.

Good for

Use it to practise breaking a small problem into steps or compare how models explain an answer.

Things to keep in mind

A detailed chain of reasoning is not proof that the final answer is correct. Check calculations and facts yourself.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull deepseek-r1:1.5b
ollama run deepseek-r1:1.5b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.

Try a prompt

A notebook costs £3 and a pen costs £2. What do two notebooks and three pens cost? Show the calculation briefly.

Try the same task with another model and compare the answers.
