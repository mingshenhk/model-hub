Phi · 3.8B

Phi-4-mini

Phi-4-mini is Microsoft's 3.8B instruction model, designed to provide useful reasoning in a smaller package.

View on Hugging Face

About this model

This is a text model with a 128K-token context window listed on its model card. Microsoft describes a focus on maths, logic and other reasoning tasks, as well as instruction following and function calling. It is useful to compare against other small models on structured questions.

Main features

  • 3.8B parameters and text input/output.
  • Training gives attention to maths, logic and reasoning.
  • The model card lists a 128K context window and function-calling support.

Good for

It may work well for short explanations, structured answers, basic maths practice and simple coding questions.

Things to keep in mind

Reasoning ability is not perfect, and a long context can use more memory. Verify calculations and important information.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull phi4-mini
ollama run phi4-mini

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.

Try a prompt

A class has 24 students. One quarter are absent. How many students are present? Show the calculation.

Try the same task with another model and compare the answers.
