A REPEATABLE TEST

Compare answers with a simple rubric

A fair test holds the prompt and computer steady, then checks answers against criteria you can explain.

Use one prompt with verifiable facts

Try this prompt with two model tags: “Summarise this notice in exactly three bullet points. Keep the date, location, and action the reader must take: The science club meets in Room 12 on Thursday 14 May at 3:30 pm. Bring your completed plant-growth chart. Tell Ms Lee by Tuesday if you cannot attend.”

Keep the exact prompt, Ollama version, computer, and context setting the same. Record the model tags. Run each one twice if you can; a single answer may not represent its usual behaviour.

Score what matters for this task

Criterion0 points1 point2 points
FactsChanges or misses key factsKeeps most factsKeeps date, room, time, and action
FormatNot three bulletsThree bullets with extra textExactly three concise bullets
ClarityHard to act onMostly clearReader can quickly see what to do

This rubric totals six points, but it is a classroom comparison rather than a published benchmark. The useful result is the evidence: which details disappeared, whether the format was followed, and how long each response took.

Write down the result

Save the prompt, model tag, scores, and one sentence describing a mistake or strength. If one model wins on accuracy but takes much longer, that trade-off may matter for your use. Try a second task before making a general claim about which model is “best.”

Check the model's own notes before testing: for example, the official Qwen3 and Gemma 4 pages list tags and package details that can change over time.
