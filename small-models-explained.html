MODEL BASICS

What does “small model” mean?

Parameter count is useful for a first comparison, but it is only one part of the experience. Download size, memory use, and answer quality describe different things.

Three numbers that answer different questions

Parameters are the learned values inside a model. A label such as 0.6B means about 600 million parameters; it does not tell you the exact download size or how much memory a running chat will need.

Download size depends on the packaged weights and their quantization. For example, the Ollama Qwen3 library lists the qwen3:0.6b package at about 523 MB and qwen3:1.7b at about 1.4 GB. These are concrete package sizes, not a promise about total runtime memory. Tags and packages can change, so check the current model page before downloading.

Runtime memory also includes the active context and other program overhead. A small download may still feel slow if the computer has little free memory or if the conversation is long.

A practical comparison

Suppose you ask both models to turn a short school notice into three bullet points. The 0.6B version may start faster and use less disk space. The 1.7B version has more parameters and may preserve more details, but it can also take more resources. Neither size label proves which answer is better for your notice.

Use the same prompt and check whether each answer keeps the date, place, and action. That small test tells you more about this task than the parameter count alone.

Try it yourself

  1. Record the exact model tag and package size.
  2. Give two models the same short task on the same computer.
  3. Compare correctness, missing details, response time, and whether the output follows your requested format.
