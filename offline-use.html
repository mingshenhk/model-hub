Using a model offline

After the model file is downloaded, a local setup can often answer prompts without internet.

PROMPT TO TRY

List three tasks I can try with this model while my computer is offline.

What to look for

Notice whether the answer follows the instruction, stays clear and gives an appropriate amount of detail.

Remember

Initial installation and model download need internet. Local software can still have other network features, so check its settings.
