Llama · 1B

Llama 3.2 1B

Llama 3.2 1B is Meta's small instruction-tuned text model, made for tasks that can run with a compact model.

View on Hugging Face

About this model

This 1B version takes text input and produces text. Its model card lists a 128K-token context window and highlights English, Spanish, German, French, Italian, Portuguese, Hindi and Thai. It is the smaller sibling of Llama 3.2 3B.

Main features

  • 1B parameters and text-only input/output.
  • Instruction tuning helps it respond to direct requests.
  • The model card lists eight languages and a 128K context window.

Good for

It can be used for quick drafts, short summaries and simple questions on a local machine.

Things to keep in mind

Its small size can make it struggle with multi-step tasks and detailed facts. Check Meta's model terms before broader use.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull llama3.2:1b
ollama run llama3.2:1b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.
