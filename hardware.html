COMPUTER NOTES

Can my computer run a small model?

There is no single answer for every computer, but a few checks can help before downloading.

Memory

Leave room for your normal apps. Start with a smaller model if the computer has limited memory.

Storage

Model files take disk space. The download size can change with the model version and quantisation.

Processor

A model can run on a CPU, though replies may be slower. Some computers can use a supported GPU.

Try a short chat

Begin with one question and see whether the speed feels comfortable for your use.
