Qwen · 1.7B

Qwen3 1.7B

Qwen3 1.7B is a small instruction-following model with more parameters than Qwen3 0.6B, while remaining suitable for local use.

View on Hugging Face

About this model

This version has 1.7 billion parameters and a 32K-token context window in its model card. Qwen3 models support more than 100 languages and are trained for reasoning, maths and coding. Extra size can help with harder prompts, but does not make every answer reliable.

Main features

  • 1.7B parameters, between the tiny 0.6B model and larger local models.
  • The Qwen3 family has multilingual and reasoning-focused training.
  • The listed context window is 32K tokens.

Good for

Try it for rewriting, short explanations, simple coding questions and comparing answers across languages.

Things to keep in mind

It may lose track of complex instructions or produce incorrect facts. Give it a clear task and review the result.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull qwen3:1.7b
ollama run qwen3:1.7b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.
