Llama · 3B

Llama 3.2 3B

Llama 3.2 3B is Meta's instruction-tuned text model with three times the parameter count of the 1B version.

View on Hugging Face

About this model

The model card lists a 128K-token context window and supports text input and output. It is tuned to follow instructions and supports English, Spanish, German, French, Italian, Portuguese, Hindi and Thai. It may give more detailed responses than the 1B model, but takes more memory to run.

Main features

  • 3B parameters, with more capacity than Llama 3.2 1B.
  • Text-only model tuned for assistant-style instructions.
  • The listed context window is 128K tokens.

Good for

Try it for summaries, everyday writing, and straightforward coding or explanation prompts.

Things to keep in mind

It still makes mistakes and may need more memory than the 1B version. Check Meta's model terms before broader use.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull llama3.2:3b
ollama run llama3.2:3b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.
