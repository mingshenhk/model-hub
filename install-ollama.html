INSTALLATION NOTES

Install and run a model

These are basic local steps. The exact installer may look a little different on each system.

Before you start

  1. Check that you have enough free disk space.
  2. Install Ollama for your operating system.
  3. Open a terminal or command prompt.
  4. Choose a model page and copy its model tag.

Example commands

ollama pull qwen3:0.6b
ollama run qwen3:0.6b

The pull command downloads the model. The run command starts an interactive chat.

If it does not start

Check the spelling of the model tag and make sure Ollama is running. A larger model may need more memory.
