Mistral · 3B

Ministral 3 3B

Ministral 3 3B is Mistral's compact multimodal assistant model, designed for local and edge use.

View on Hugging Face

About this model

The model card describes a 3.4B language model with a 0.4B vision encoder and a context window of up to 256K tokens. It can understand images as well as text, supports many languages including Chinese, and includes features such as tool use and structured JSON output.

Main features

  • Text and image understanding in a compact model family.
  • Multilingual support includes Chinese.
  • The card lists up to 256K context and support for tool use and JSON output.

Good for

Try it for image descriptions, short multilingual chats, or returning a small amount of structured information.

Things to keep in mind

Image input and long context can need extra resources. Tool-use features do not mean the model can safely take actions by itself.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull ministral-3:3b
ollama run ministral-3:3b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.
