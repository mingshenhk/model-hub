Small model glossary

A few words that appear on the model pages.

Parameter
A learned value inside a model. The count is often used as a rough way to describe model size.
Local model
A model that runs on your own computer using compatible software.
Prompt
The instruction or question that you give to a model.
Quantisation
A way of storing model values with fewer bits, often to reduce file size and memory use.
Distilled model
A smaller model trained to learn patterns from a larger model.
Context
The text a model can consider during one conversation or response.
