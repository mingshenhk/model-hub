Gemma · E2B

Gemma 4 E2B

Gemma 4 E2B is Google's smaller edge model, designed to bring text and multimodal tasks to devices with limited resources.

View on Hugging Face

About this model

E2B has about 2.3B effective parameters (5.1B including embeddings). Its model card lists a 128K context window. The Gemma 4 family supports text, image and audio input, although local features depend on the software and hardware being used.

Main features

  • Intended for edge and on-device use.
  • The family supports text, and also has image and audio abilities.
  • Its listed context window is 128K tokens.

Good for

It is a reasonable option for everyday questions, short writing help and trying a multimodal model locally.

Things to keep in mind

It is still a small model. Image or audio use can need more resources than text chat, and answers should be checked.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull gemma4:e2b
ollama run gemma4:e2b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.

Try a prompt

Give me three simple ideas for organising a small study desk. Keep each idea to one sentence.
