Gemma · E4B

Gemma 4 E4B

Gemma 4 E4B is the larger of the two Gemma 4 edge models on this site, with more effective parameters than E2B.

View on Hugging Face

About this model

E4B has about 4.5B effective parameters (8B including embeddings). Its model card lists a 128K context window. Gemma 4 supports text, image and audio input, so it can be useful beyond text chat when the local setup supports those inputs.

Main features

  • More effective parameters than Gemma 4 E2B.
  • The family supports text, images and audio.
  • A listed 128K context window can help with longer input.

Good for

Try it for longer summaries, everyday writing, and multimodal experiments on a suitable computer.

Things to keep in mind

It needs more memory and processing than E2B. A long context does not mean it will understand every detail correctly.

Run it with Ollama

Install Ollama first. In a terminal, download the model and then start a chat:

ollama pull gemma4:e4b
ollama run gemma4:e4b

The first command downloads the model. Run the second command to start chatting. Type /bye to leave.
