WAYS TO RUN MODELS

Choose a local runtime

Ollama

A straightforward way to download and chat with small models on your computer.

See the Ollama setup

vLLM

A serving engine for running model APIs, often used with supported GPUs.

Read the vLLM quickstart

llama-server

Serve a local model through a browser interface and an OpenAI-compatible API.

Explore llama.cpp server

These are different ways to run models locally. The right choice depends on your computer and whether you want a chat app or an API.
